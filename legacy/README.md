# Legacy code

Thư mục này giữ lại các nhánh cũ để tham khảo sau khi dự án được gom về một đường chạy chính bằng React + Express:

- `servlet-jsp/`: ứng dụng Java Servlet/JSP + Tomcat cũ
- `spring-boot-api/`: API Spring Boot thử nghiệm
- `momo-node-proxy/`: proxy MoMo từng chạy song song với nhánh Java
- `database/`: dump và script migrate cũ
- `docs/`: tài liệu thuyết trình / NetBeans cũ

Không thư mục nào trong đây còn được dùng bởi lệnh `npm run dev` hoặc `run-all.bat` ở root.
