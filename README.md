# Huy Perfume - Website Bán Nước Hoa

Ứng dụng web bán nước hoa được xây dựng bằng Java Servlet, JSP, MySQL.

## 🚀 Bắt đầu nhanh

### 1. Tải thư viện
```bash
# Windows
download_libraries.bat

# Hoặc tải thủ công vào web/WEB-INF/lib/
```

### 2. Thiết lập Database
```bash
mysql -u root -p < database_setup.sql
```

### 3. Chạy ứng dụng
- Mở project trong NetBeans
- Nhấn F6 để chạy
